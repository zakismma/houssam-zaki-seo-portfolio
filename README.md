## Deploy on GitHub Pages

1. Go to repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `root`
4. Your portfolio will be live at `https://yourusername.github.io/houssam-zaki-seo-portfolio/`
